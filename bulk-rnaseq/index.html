Statistical Formulation: Overdispersed Poisson Failure

In biological sequencing replicates, sample variance exceeds the mean count (σ² > μ), violating standard Poisson assumptions. DESeq2 addresses this overdispersion by parameterizing the Negative Binomial distribution:

Negative Binomial Count Model

K_ij ~ NB(μ_ij, α_i) where variance Var(K_ij) = μ_ij + α_i · μ_ij².
Here α_i is the gene-specific dispersion parameter estimated through empirical Bayes information sharing across the whole transcriptome.
  • Multiple Testing Correction: Benjamini-Hochberg False Discovery Rate (FDR < 0.05).
  • Normalization Method: Median-of-ratios size factor scaling accounting for sequencing depth and library composition.
  • Log-Fold Transformation: apeglm empirical Bayes adaptive shrinkage for ranking stability.

GSE183947 TNBC Differential Dysregulation

Across 1,847 statistically significant DEGs (|log&sub2;FC| ≥ 1.5, FDR < 0.05), clean transcriptional bifurcation separates aggressive TNBC biology from non-tumor controls:

  • Up-regulated in TNBC (n = 923): Hyperactivation of oncogenic kinase cascades (AKT1, EGFR), proliferation markers (MKI67), and invasive migration factors.
  • Down-regulated in TNBC (n = 924): Complete loss of hormone receptor identity (ESR1, PGR), ERBB2 downregulation, and tumor-suppressive adhesion molecules.
  • Biological Pipeline Integration: Transkriptomic outputs directly initialize downstream WGCNA scale-free network construction and AlphaFold2 allosteric virtual screening.
