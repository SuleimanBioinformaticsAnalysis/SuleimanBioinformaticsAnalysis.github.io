## 🔬 Core Interactive Capabilities

- **Interactive Transcriptomic Volcano Plot & DEGs:** Dynamic SVG volcano plot with customizable fold-change and FDR thresholds, linked directly to 1,847 significant genes (DESeq2, FDR < 0.05).
- **Single-Cell Transcriptomics:** Cluster marker tables (clusters 0-8) and high-resolution PBMC UMAP visualizations (Seurat v4).
- **Machine Learning & WGCNA:** Nested 5-fold cross-validated Random Forest oncology classifier (AUC-ROC = 0.91) and scale-free co-expression network analysis (Turquoise module, AKT1 hub).
- **Structural Biology & Molecular Docking:** AlphaFold2 human AKT1 model metrics (mean pLDDT 92.4), PDB 3O96 crystal structure comparisons, and AutoDock Vina binding evaluations for allosteric (MK-2206, -9.4 kcal/mol) vs. ATP-competitive inhibitors.
- **Clinical Variant Interpretation:** High-confidence NIH ClinVar variant curation from 609K personal SNP arrays (pharmacogenomics, protective, and disease susceptibility alleles).
- **PLOS ONE Manuscript Highlight:** Comprehensive abstract, figures, and methodology summaries with direct private repository data request links.
